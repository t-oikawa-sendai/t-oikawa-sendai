# 教材案内

授業や自主学習に使う教材の入口です。教材名を選ぶと、GitHubの教材ページを開きます。

その他の教材は、原則として限定公開です。授業で案内する取得先を利用してください。

### 限定公開教材を開くには

閲覧権限が設定されたGitHubアカウントでログインしてください。リンクを知っているだけでは、Privateの教材は閲覧できません。ページが見つからない場合は、利用中のアカウントを確認し、講師へ連絡してください。
