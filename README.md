# 生徒向け学習リポジトリ

授業や自主学習に使える公開資料とサンプルをまとめています。

## 学習の入口

- [scao-learning-hub](https://github.com/t-oikawa-sendai/scao-learning-hub) — 学習資料を探すための入口です。
- [scao-learning-kit](https://github.com/t-oikawa-sendai/scao-learning-kit) — 初学者向けに、AIの活用と設計を学ぶ資料です。現在作成中です。

## 設計とAI

- 🆗[design-document-templates](https://github.com/t-oikawa-sendai/design-document-templates) — 7文書構成の設計テンプレートと使い方の説明です。
- [scao-basic-design-templates](https://github.com/t-oikawa-sendai/scao-basic-design-templates) — 基本設計に進む前に確認する項目をまとめたチェックリストです。
- 🆗[ai-setup-materials](https://github.com/t-oikawa-sendai/ai-setup-materials) — AIに調査・設計・コード生成・レビューの役割を分けて使うための入門資料です。
- [spec-core-architecture-o](https://github.com/t-oikawa-sendai/spec-core-architecture-o) — 仕様を中心にAIと開発を進める考え方を学ぶ資料です。

## アプリのサンプル

- 🆗[dokoTsubu-platform](https://github.com/t-oikawa-sendai/dokoTsubu-platform) — JavaのWebアプリ「どこつぶ」の学習用サンプルです。
- [office-addin-dokotsubu-demo](https://github.com/t-oikawa-sendai/office-addin-dokotsubu-demo) — Office Add-inとExcel VBAを使った教材用モックです。
